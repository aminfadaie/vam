ذخیره و همگام‌سازی بین دستگاه‌ها

برای اینکه پرداخت‌هایی که ثبت می‌کنی روی سایت ذخیره شود و روی گوشی و کامپیوتر یکی باشد، این سایت به یک «توکن گیت‌هاب» نیاز دارد. بدون توکن، تغییرات فقط روی همین دستگاه می‌ماند.

ساخت توکن (یک بار)

  1. این صفحه را باز کن: github.com/settings/personal-access-tokens/new
  2. یک اسم بده (مثلاً vam-site) و تاریخ انقضا را طولانی انتخاب کن.
  3. در Repository access گزینه‌ی Only select repositories و فقط مخزن vam را انتخاب کن.
  4. در Permissions ← Repository permissions، مورد Contents را روی Read and write بگذار.
  5. Generate token را بزن، توکن را کپی کن و اینجا وارد کن.

تغییر رمز سایت

برای تغییر رمز، توکن باید روی این دستگاه تنظیم شده باشد. بعد از تغییر، روی دستگاه‌های دیگر باید رمز جدید را وارد کنی.
